# Exegol: pentest write-ups

> Built at **Epitech Rennes** · B-SPE-321 · Cybersecurity specialization · September 2026

## Overview

A series of offensive security challenges solved from the **Exegol** environment. Each challenge has its own write-up: properties (difficulty, techniques, tools) followed by detailed steps, from reconnaissance to capturing the `user.txt` and `root.txt` flags.

## Features

- `Fuzz/`: web enumeration and hidden content discovery
- `Injection/`: injection exploitation
- `Cracking/`: password and encrypted file cracking
- `Reverse/`: reverse engineering
- Screenshots and commands for every step

## Tech stack

`Exegol` · `nmap` · `ffuf` · `John the Ripper / Hashcat` · `gpg` · `Linux`
